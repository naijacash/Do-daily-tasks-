Naija Cash
About
Naija Cash is an online platform designed to help users access and manage cash-related services through a simple dashboard.
Features
User registration and login
Personal user dashboard
Account/profile management
Cash balance display
Transaction records
Easy-to-use interface
Getting Started
Create an account.
Log in to your dashboard.
Complete your profile.
Use the available features from the dashboard.
Project Status
🚧 This project is currently under development.
Important Note
Naija Cash is a project/demo platform. Do not enter real banking passwords, card details, PINs, or other sensitive financial information while testing it.
